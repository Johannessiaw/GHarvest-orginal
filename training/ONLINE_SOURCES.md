# Online research sources used for Kofi voice engineering

The following sources were reviewed on 2026-09-09:

1. OpenAI Realtime API reference: server VAD, Semantic VAD, audio transcription language hints, and realtime interaction behavior.
2. OpenAI Audio API reference: speech generation, supported voices, speed, and current TTS request fields.
3. OpenAI Models documentation: current GPT-5.6 model family and the `gpt-5.6-luna` model ID.
4. Ghana NLP Community `ghana-speech`: multilingual Ghanaian speech data covering 42 language subsets.
5. Ghana NLP Community `ghana-speech-eval`: held-out Ghanaian-language ASR benchmark; evaluation only.
6. Ghana NLP Community `ghana-speech-id`: Ghanaian/West African spoken-language identification model covering 41 languages.
7. Ghana NLP Community `Ghana_English-Twi_Code-switching_Speech-ipa`: English-Twi code-switching speech with an IPA-derived representation.
8. Ghana NLP Community `twi-tts-asr`: Twi speech/audio-text data for TTS and ASR experimentation.
9. Ghana NLP Community `navigation-corpus-twi-speech`: spoken Twi navigation data.
10. Ghana NLP Community `ghana-english-asr-2700hrs`: large Ghanaian-English ASR corpus for accent/domain adaptation.

URLs are deliberately kept in the source-code documentation as dataset/model identifiers instead of hard-coding third-party download URLs into runtime code.
